## §1 测试工具：Web「PLC 调试」面板

位置：Web 界面（默认 8080 端口）「手动命令」卡片下方的 **PLC 调试（寄存器/命令直发）** 卡片。

| 操作 | 方法 | 用途 |
|---|---|---|
| 下发命令 | 填 PLC 编号（如 `1`）→ 站口 1~16 → 命令码（任意 0~65535，常用 1=写入货物ID / 2=清除货物ID）→ 填载具 ID（命令码 1 必填）→ 点「下发命令」→ 二次确认 | 直发命令协议：写 ID 区 → 写 401+站口 命令 → 写 400 编号 → 等回显（306 编号 + 307+站口）；执行后结果区自动追读 306~322 回显 |
| 查看寄存器 | 「PLC 详情」页 4 栏：状态区 0~49 与回显/握手区 306~340 自动刷新；ID 区 50~305 与命令区 400~672 点「读原始值/读取」按需拉取 | 验证任意寄存器区的值（回显核对、ID 回读比对、字节序检查） |
| 写寄存器 | 填 PLC 编号 + 写地址 + 值（逗号分隔）→ 点「写寄存器」→ 二次确认 | 边界/异常路径测试（**危险**：直写 PLC，勿在设备运行时乱写状态区）；如手动回写 340=0 |

**注意**：
- 面板命令**直走 PLC 命令协议**，绕过业务逻辑——不动库存台账、不发 MCS 事件，适合单独与 PLC 调协议。
- 业务全链路（含台账/事件/S6F11）用「手动命令」面板的 安装/移除 测试。
- 面板每次操作后建议顺手读 306~322 回显区核对；操作结果可在「运行日志」面板按「命令」过滤查看。

## §3 结果回填闭环

1. 每项通过后：填「实际结果/日期/确认人」，证据列存截图/日志段（`bufferc-YYYYMMDD.log` 对应时间戳 + Web 界面截图）。
2. 日志行格式（2026-08-17 起）：`[日期 时间][级别][类别][#序号] 消息`；`[Cmd]` 行现带 PLC 编号（如 `PLC1 站口4`）；命令生命周期明细在审计日志 `bufferc.audit-YYYYMMDD.log`。
2. 现场确认值（字节序/unit_id/告警码表等）**回填开发文档 §5 待确认项**并更新本表 §0。
3. 失败项：按《现场使用手册.md》§5 故障排查表处置，复测通过后关闭。
