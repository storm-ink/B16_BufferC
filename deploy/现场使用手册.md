# BufferC 现场联调使用手册（2026-08-11）

> 产物：BufferC.Host.exe（win-x64 自包含，无需安装 .NET）/ BufferC.Host（linux-x64 自包含，CentOS 7）
> 本手册为联调执行层；核对标准回溯到开发文档（§2 PLC 规范 / §3 MCS 规范 / §3.6 场景）。

## §0 前置闸门（赴现场前必须通过）

1. **本机预演 PASS**：在开发机跑 `bash deploy/联调预演.sh`，输出 `[PASS]` 且退出码 0。
2. **证据留存**：预演日志 `publish/simulator/sim.log` + `bufferc-wsl.log` 归档到本次联调记录目录。
3. 未通过预演不得赴现场（部署形态、产物、业务链路已验证，现场只剩填真 IP 与确认项）。

## §1 部署

1. 整个文件夹拷到笔记本（如 `D:\BufferC\`）或按部署说明.md 装到 CentOS 7 服务器（/opt/bufferc）
2. 编辑 `config.json`：
   - `plcs`：按现场实际填 15 台 PLC 的 `ip` / `unitId`（1 或 255，现场确认）/ `byteOrder`（"high" 或 "low"，货物ID 乱序时切换）
   - `hsms.listenPort`：默认 5000（MCS 连入端口）
   - `hsms.svidCarrierFormat`：S1F4 载具结构（默认 "l4"；MCS 解析报错时试 "l2"）——**改配置即可，不用改代码**
   - `hsms.logFrames`：协议帧日志开关（联调开、运行期可关；**联调期也可 Web /api/debug 运行时切换**；关时跳过 HEX/SML 转换省 CPU）
   - `logLevel`：error|warn|info|debug|trace（默认 info；联调开 trace 看 Modbus 帧——需同时 `logModbusFrames: true`）
   - `logRetentionDays`：滚动日志保留天数（默认 7，启动与跨天时自动清理过期文件）
   - `auditFile`：审计日志基名（默认 `bufferc.audit.log`；置空整体关闭审计通道）
   - `reconcileStrict`：对账严格模式（默认 false 只记差异不删；true 时 InventoryDataSend 删除 MCS 未包含的本地条目）
   - `pollIntervalMs`：轮询周期，现场可调（默认 500）
   - 配置错误（IP 空/端口冲突/logLevel 非法等）启动时会**明确报错并退出**，不会带病运行
3. 运行：`BufferC.Host.exe config.json`（控制台按 Ctrl+C 退出）
4. 日志：控制台 + `bufferc-YYYYMMDD.log`（运行日志，按天滚动保留 7 天）+ `bufferc.audit-YYYYMMDD.log`（审计日志，SECS 收发摘要/命令全生命周期/告警/对账——现场留档证据；同目录，UTF-8 带 BOM）

### Windows 防火墙（笔记本联调时）

MCS 或 PLC 从别的机器连笔记本时需放行（管理员 PowerShell / cmd）：

```bat
netsh advfirewall firewall add rule name="BufferC-HSMS" dir=in action=allow protocol=TCP localport=5000
netsh advfirewall firewall add rule name="BufferC-Web"   dir=in action=allow protocol=TCP localport=7001
netsh advfirewall firewall add rule name="BufferC-PLC"   dir=in action=allow protocol=TCP localport=502
```

> 预演环境（WSL 仿真）里 WSL→Windows 入站可能被防火墙**瞬态拒绝**（表现为 Connection refused），重跑一次即通——属已知现象，不是程序问题。

## §5 故障排查表

| 症状 | 排查步骤 | 处置 |
|---|---|---|
| PLC 连接失败 | ① 笔记本 `ping <PLC IP>` ② PLC 侧确认 502 监听（`ss -tlnp`）③ 核对 unitId（1/255）④ Windows 防火墙规则 | IP/端口/unitId 改正后重启 |
| 端口冲突（5000/7001 起不来） | `netstat -ano | findstr 5000` 看占用 | 改 config 的 hsms.listenPort / webPort |
| S1F4 解析报错（MCS 侧） | 帧日志看 `→MCS S1F4` 的 HEX/SML 结构 | 切换 `svidCarrierFormat` l4/l2 |
| 载具 ID 乱码/字节序 | Web 寄存器视图对照 V8 表看 HEX | 切换 `byteOrder` high/low |
| 命令超时/失败 | ① 帧日志确认命令已写入 PLC（MODBUS TX 看 FC16 地址 4xx）② PLC 侧看 400 编号与 306/307~322 回显 ③ 调 `echoTimeoutMs`/`echoRetryCount` | 超时参数放宽；仍失败按 §5 记 9001 悬空命令 |
| 事件缺失/顺序乱 | 帧日志 `←MCS`（入站 HEX+SML）与 `→MCS`（出站 HEX+SML）对照 | 断线不补报为已知行为，重连后 S1F3 全量查询一致 |
| Web 打不开 | ① `webPort` 是否为 0 ② 防火墙 7001 ③ 本机先 curl localhost:7001 区分程序/网络 | 放行防火墙 |
| 需要更细日志 | Web `/api/debug`：POST `{enabled:true}` 开帧日志、POST `{level:"trace"}` 开明细（需 config `logModbusFrames:true`） | 联调完切回 info 关帧日志 |

**帧日志怎么看**：`←MCS`（入站，HEX+SML）、`→MCS`（出站，HEX+SML）、`MCS→`（ACK/T3 匹配）、`MODBUS TX/RX`（trace 级，需 logModbusFrames）。全帧行含 `HEX=` 与折叠为单行的 `SML=`；无 `HEX=` 的 `←MCS/→MCS` 行是审计摘要（常开，不受 logFrames 约束）。

**日志行格式**（2026-08-17 起）：`[日期 时间][级别][类别][#序号] 消息`——级别五档 ERROR/WARN/INFO/DEBUG/TRACE（异常路径已按级别标定，现场 grep `[ERROR]` 快速定位故障）；审计行级别位为 `[AUDIT]`。普通日志与审计共用 `#序号`，两文件可互相关联（如命令入队→执行→完成）。

**审计日志内容**：SECS 收发摘要（SxFy+sys+方向）、S2F41 参数、命令全生命周期（入队→执行→完成 seq=N/失败）、S5F1 9001 悬空命令告警、对账（InventoryDataSend 更新/差异/汇总）、CIM 状态事件、T3 超时。现场留档交 `bufferc.audit-YYYYMMDD.log` 即可。

## §6 证据留存

- 每个检查项：截取 `bufferc-YYYYMMDD.log`（运行日志）与 `bufferc.audit-YYYYMMDD.log`（审计）对应日志段存档
- Web 界面截图（状态栏 + 对应站口/告警）
- `config.json` 快照（最终生效版，含 byteOrder/unitId/svidCarrierFormat 等确认值）
- 联调记录表：检查项编号 + 结果 + 日期 + 确认人（即 §2/§3/§4 表格）
- **回填闭环**：手册 checkbox 勾选 ≠ 闭环——回来后把确认值回填开发文档 §5 待确认项（A/B/C/D/E 对应条目），并同步本手册"已确认值"

## §7 已知限制（当前版本）

- 15 台 PLC 并发：支持（每台独立任务），现场按实际台数配置
- 502 InventoryUpdateRequest：已裁剪（MCS 流程无触发场景）；一致性靠 S1F3 全量查询比对
- AGVC HTTP 接口：仅出站 queryMachines（2→1 到货无 ID 时查询货物 ID 直接回传，BufferC 自行写 PLC）；入站接口（送达通知/站口服务状态）已按现场要求移除（2026-08-14）
- **pushDeviceStatusInfo 载荷不含 inputRequest/outputRequest**（现场确认不发送，已实现）
- **事件报告配置（S2F33/35/37）未实现**：MCS 已确认不使用（2026-08-17），事件采用「无配置直接推送」模式
- **载具 ID ≤32 字符**（现场确认 2026-08-17；ID 区 16 寄存器）
- **BCR NG 流程已取消**（现场确认 2026-08-17）：扫码失败 UNK 上报无对应现场流程；501 事件仅正常扫码路径
- 库存台账：SQLite 持久化（config.json 的 dbPath；null=内存模式）
- SCState 固定 2（PAUSED，现场约定：MCS 不发 PAUSE 只走 RESUME 流程）；PAUSE/RESUME 均回 HCACK=0，RESUME 后发 CEID 103
- 断线期间变化不补报事件（仅状态同步 + 日志）
